محفوظ على هذا الجهاز
الحضور: رمادي = لم يسجل، حضور / تأخير / غياب / لا ينطبق.
الدرس: رمادي = لم يسجل، تحضير / إلقاء / لا ينطبق / لم يتم.
لو الحضور = غياب، الصلاة والدرس والاجتماع بتتحول لم يتم تلقائي. لو التناول = لم يتم، الشماس بيتحول لم يتم تلقائي.
عشية: تم أو لم يتم بس.
لا ينطبق مش بتدخل في المجموع. المجاميع بتجمع الأسابيع داخل الفلتر. "ناقص" = ما اتعملش افتقاد / تسبحة / تناول في آخر 4 أسابيع. اضغط اسم الخادم لتقريره.
